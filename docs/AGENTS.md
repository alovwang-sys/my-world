# 文档维护约定

本目录遵循根目录 [AGENTS.md](../AGENTS.md)。文档职责见 [索引](README.md)。

- 当前实现、未来提案与历史材料分别写在所属文件；不能用计划描述替代当前状态。
- 一个事实有一个维护入口，其他文档链接过去。详细契约可链接源码，避免复制整份 schema 或命令清单。
- 操作指南按前提与执行顺序写，参考文档按责任与查询范围写。Key、部署标识、私有对话用占位符。
- 文档和代码在同一改动中更新。记录验证日期、范围与限制，不能把离线模拟说成真实 API 或用户试用。
- `archive/` 冻结历史，不修成第二套活动文档；新结论放活动文档并链接相关历史。
- 使用本地相对链接，运行 `npm run check:docs`。不为维护这组 Markdown 引入文档网站框架。
